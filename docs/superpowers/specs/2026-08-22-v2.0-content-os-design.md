# v2.0.0「内容经营操作系统」设计定档

> 2026-08-22 专家团定档。输入：roadmap.md 中期方向、第一性原理推演（2026-08-15）、三路外部调研（satori / GSC AI 数据 / GH Actions PR 管道）。本文是 v2.0.0 的决策记录与实现蓝图。

## 定档决策（专家团裁定）

| # | 决策点 | 裁定 | 理由 |
| --- | --- | --- | --- |
| D1 | og:image 尺寸标准 | **800×450 → 1200×675**（16:9 且满足 Google Discover ≥1200px 宽），全站补 `max-image-preview:large` | Discover 大图预览硬门槛；图片搜索已是 2026 流量入口（docs/seo.md 2026-03 起 og:image 为选图首选来源） |
| D2 | Astro 升级时机 | **v2.0.0 锁死 Astro 5.x 不动**；5→6→7 迁移独立成 v2.0.0 后的小版本 | Astro 7 已 GA（2026-06-22）但 v6 强制 Content Layer 迁移、v7 换 Rust 编译器不再静默修正 HTML——开发期锁变量优先 |
| D3 | 手册承载 | **不新增章节**：管道 + 多站 + AI 引用写进 dev 手册现有 `ai-ops` 章（zh/en），章节数维持 learn 11 / dev 7 | 降低全仓计数连锁面；v2.1 管道扩展生成器时再考虑独立章 |
| D4 | 管道首期任务 | **只做 `import-csv`**（bulk-new-posts 脚手架），codes 同步等生成器留 v2.1 | 确定性优先，零 LLM 进 CI |
| D5 | 版本语义 | 模板仓库**零 breaking**（四件全加法）；`anvilwiki-ops` 0.x→**1.0.0** 承载唯一实质契约变化（MCP 工具签名加 `site` 参数）；staying-up-to-date.md MAJOR 措辞改为「重大里程碑；含 breaking 必附迁移说明」 | 不人为制造 breaking 伤害存量 fork merge 体验 |
| D6 | AI 引用数据通道 | CF Web Analytics referrer host 分组（主）+ GSC `AI_OVERVIEWS` appearance 探测（实验）+ GSC UI CSV 导入（兜底） | GSC API 不暴露 gen-AI 报告数据（2026-08 核实，仅 UI + CSV） |

## 范围（四件核心）

1. **内容管道 v2**：`.github/workflows/auto-content.yml`（workflow_dispatch + create-pull-request@v8 draft PR）+ 八道门禁抽成 composite action（`.github/actions/gates`）供 ci.yml 与管道共享——**门禁前置，绿灯是开 PR 的前提**（GITHUB_TOKEN 开的 PR 本就不自动跑 CI，2026 起处于待批准状态，此设计零 secret 规避该限制）。LLM 永不进 CI。
2. **anvilwiki-ops 1.0.0**：多站注册表 `~/.config/anvil-ops/sites.toml`（`[[sites]]` name/path/siteUrl 覆盖，永不存凭据）+ `--site`/`--all` + `sites list/add/remove`；默认行为（cwd 自动发现）不变。AI referrals（CF referrer）+ AIO 探测 + `metrics --import-aio <csv>`。
3. **`pnpm gen-covers`**：satori 0.33 + @resvg/resvg-js + subset-font；1200×675 PNG；CJK 按标题字符运行时子集（Noto SC/JP OTF 缓存于 node_modules/.cache，不进 git）；Latin 字体内置仓库；manifest hash 缓存；`--force`/`--out`。
4. **`AffiliateSuggestion`**：config 层 `src/config/affiliates.ts`（默认空 = 不渲染，保 Lighthouse 4×100 与 fork 纯净）+ 文末建议位组件，i18n 走 locales JSON。

## 不做（本版）

邮件订阅、选品数据脚本、preferred sources、Astro 6/7 迁移、管道 codes 同步生成器 —— 全部推 v2.1+。

## 验收门

- root：typecheck / lint / test / check-config / build / check-content / check-links / check-i18n / template-audit 全绿
- ops：typecheck / test / build 全绿（~75 tests）
- gen-covers 对 demo 全量文章（en+ja）实跑成功（覆盖 Latin 与 CJK 路径）
- workflows smoke 测试：ci.yml 与 composite action 门禁一致性
- 发版触点清单按 docs/development.md 七步 + CHANGELOG 2.0.0 迁移说明（预计「常规 merge，无迁移步骤」）
